A graph is a set of [[node]] objects joined by [[edge]] links. Everything else here is a question about that one structure: how far apart things are, which ones matter, how the whole thing holds together. An [[adjacency-matrix]] is one way to write it down.

See also: [[path]], [[cycle]], [[connected-component]], [[clique]].
